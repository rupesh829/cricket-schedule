Browsers block network requests (Google Sheets, PWA features) when a file is opened directly. You need to serve it over HTTP.

Option 1 — Local server (instant):
cd /Users/nirup/git/ScheduleScrapper && python3 -m http.server 8080
Then open http://localhost:8080/cricket_schedule.html in your browser.
Option 2 — GitHub Pages: Push to a repo and enable Pages in repository Settings.
